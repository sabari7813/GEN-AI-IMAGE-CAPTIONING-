# Gen AI-Powered Image Captioning

## Project Overview
Gen AI-Powered Image Captioning is an AI-based application that automatically generates meaningful textual descriptions for uploaded images using the BLIP (Bootstrapping Language-Image Pre-training) model.

## Features
- Upload images through an interactive interface
- Automatically analyse image content
- Generate meaningful captions using AI
- Simple and user-friendly interface

## Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- BLIP Pre-trained Model
- Gradio
- Pillow

## How It Works
1. User uploads an image.
2. The image is processed using BLIP Processor.
3. The pre-trained BLIP model analyses the image.
4. The model generates a descriptive caption.
5. The caption is displayed to the user.
